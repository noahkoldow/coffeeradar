# Banner Scene Showcase

This document previews the reduced, quality-focused banner direction.

## Visual Direction

- Keep banner readable and calm.
- Prefer fewer motifs with cleaner silhouettes.
- Keep weather as the primary signal.
- Use location flavor only when it is unmistakable.

## Curated Scene Set

| Scene | Trigger | Motif |
| --- | --- | --- |
| City skyline | Clear urban context | Minimal skyline + one hero landmark |
| Mountain pass | Mountain context | Ridge line + alpine ground motion |
| Coastal line | Coastal context | Horizon wave + low shoreline profile |
| Neutral weather | Unknown context | Weather-only sky + simple terrain |

## Landmark Examples

- Berlin: Brandenburg Gate + Fernsehturm.
- Tokyo: Skytree-style tower silhouette.
- Washington, DC: Monument + dome rhythm.
- Sydney: Opera-shell and bridge arc profile.

## Quality Rules

- One primary landmark per scene.
- Avoid crowded overlays.
- Keep line weights consistent.
- Keep motion subtle and loop-safe.
